shield Probing & Mount Protection

Automatically triggers an asynchronous probe (Low Priority) whenever a new .strm file is detected by the library manager.
Deletes the .strm file and removes it from the library when its pre-flight check returns a deterministic HTTP 404. Automatically halted when the circuit breaker is tripped.
When playback starts on an episode, automatically enqueues the immediately following episode into the High Priority probe lane so its stream info is resolved before the current episode finishes.
Once runtime is resolved on a .strm item, creates virtual chapter markers every 5 minutes if 0 chapters exist, enabling users to jump around effortlessly without heavy chapter extraction.
